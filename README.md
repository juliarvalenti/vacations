# vacations

Family photo albums, migrated from Google Sites. Astro static site deployed to GitHub Pages.

- `scripts/harvest.py` — pulls structure + images from the original Google Sites into `content/*.json` and `public/assets/`
- `src/` — Astro site (components: Grid, Carousel, Lightbox, TopBar, FloatingToc)
- `npm run dev` to work on it locally
